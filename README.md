An entry for the [make.fun](https://make.fun/c/u-boothlord-one-line-to-your-younger-self-22e97f76) competition **"One Line to Your Younger Self"**: write the single line you would send your younger self if one line were all you got.

## The entry

> Kid, one day a little girl will call you Dad and mean it — so be the man she already thinks you are.

## How it works

`main.py` (Python 3, stdlib only) writes that one line to `/output/entry.txt`, creating `/output` if needed. The line is 100 characters, one line, in English.

Run it with:

```sh
python3 main.py
```
